### ОТЧЕТ

**Вывод**

В ходе выполнения работы была реализована имитационная модель простейшего (пуассоновского) потока запросов на сервер. Процесс моделирования основывался на генерации случайных интервалов времени между событиями, распределенных по экспоненциальному закону. Для получения достоверных статистических данных эксперимент был повторен $N=1000$ раз, что позволило накопить массив данных о количестве запросов, поступивших за выбранный интервал времени $T=60$.

Анализ полученных результатов показал, что построенное эмпирическое распределение имеет характерную форму, соответствующую теоретическому закону Пуассона. Основным подтверждением адекватности модели стало сравнение расчетных характеристик: вычисленные значения выборочного среднего и дисперсии оказались близки между собой и практически совпали с теоретическим параметром $\lambda T$. Незначительные отклонения объясняются случайной природой процесса и ограниченным числом итераций.

В итоге можно сделать вывод, что данная модель корректно отражает динамику реального потока заявок. Она позволяет эффективно прогнозировать среднюю нагрузку на сервер и оценивать вероятность возникновения пиковых значений, что необходимо для проектирования стабильных вычислительных систем.
