### Марковская модель погоды

**Задание:**  
Смоделировать погоду по дням:

- 1 — ясно  
- 2 — облачно  
- 3 — пасмурно  

Единица времени — **1 день**.  
Задать интенсивности переходов между состояниями.

**Требования:**
1. Выполнить моделирование в «реальном» времени с визуализацией.
2. Провести статистическую обработку результатов.
3. Сравнить эмпирическое распределение с теоретическим стационарным.

### ОТЧЕТ

В ходе выполнения работы была разработана и исследована математическая модель погоды на основе непрерывной цепи Маркова с тремя состояниями: «ясно», «облачно» и «пасмурно».

Моделирование осуществлялось в режиме реального времени с визуализацией динамики частот состояний, что позволило наглядно наблюдать за эволюцией системы. Интенсивности переходов между состояниями задавались пользователем через матрицу генератора Q, а траектория процесса моделировалась методом статистических испытаний с экспоненциальным распределением времени пребывания в каждом состоянии.

Для расчёта теоретического стационарного распределения была решена система линейных уравнений π · Q = 0 с условием нормировки Σπᵢ = 1 методом Крамера, что обеспечило высокую точность аналитического решения.

Сравнение эмпирических частот, полученных в ходе моделирования, с теоретическими значениями показало их близкое совпадение при достаточной продолжительности эксперимента, что подтверждает:

- эргодичность построенной цепи
- корректность реализации алгоритма

Результаты моделирования, включая временные ряды состояний и итоговые распределения, экспортируются в файл формата .csv для дальнейшего анализа.

Таким образом, работа демонстрирует практическое применение теории цепей Маркова для моделирования стохастических процессов и подтверждает сходимость эмпирических оценок к теоретическому стационарному распределению при увеличении времени наблюдения.
